# 賞味期限管理

元のGASアプリの入力・在庫・在庫切れ画面をGitHub Pagesで使えるようにした静的Webアプリです。ブラウザのローカルストレージに在庫・購入履歴・絵文字マスターを保存します。

## GitHub Pagesで使う

1. ZIPを展開し、中のファイルをGitHubリポジトリのルートに追加します。ルート直下に `index.html`、`app.js`、`storage.js` がある状態にします。
2. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、公開ブランチ（例 `main`）、**/ (root)** を選んで保存します。
3. Pagesの設定に表示されるURLを開きます。

手元で試す場合は、展開したフォルダで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。

## 旧スプレッドシートから移行する

1. 元のスプレッドシートで **拡張機能 → Apps Script** を開き、スクリプトファイルを追加して `migration/ExportBackup.gs` の内容を貼り付けます。
2. `exportExpiryBackup` を選んで実行します。初回はスプレッドシートとGoogle Driveへのアクセスを許可します。
3. 実行ログのリンクを開き、Driveに作成された `food-expiry-migration-YYYY-MM-DD.json` をダウンロードします。
4. 新しいアプリの **データのバックアップ・復元 → JSONを読み込む** から選択し、件数を確認して復元します。

移行用コードは `Items`、`Archive`、`EmojiMaster` を読み取ります。公開リポジトリへのアップロードはアプリのソースファイルだけにしてください。商品やメモを含むJSONは手元で管理してください。

## バックアップと復元

**JSONを書き出す** で在庫・履歴・絵文字マスターをまとめて保存します。**JSONを読み込む** と、内容を検証して件数と置き換えの確認を表示します。確認後、現在のデータがすべて置き換わります。

保存先は使用中のブラウザと公開URLに紐づきます。別の端末やURLへ引き継ぐときや、ブラウザのサイトデータを消去する前はJSONを書き出してください。GASで設定していたGmail自動通知は静的Web版への移植対象外です。
